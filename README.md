# 旧时光 · 童年地图

一个可以走进去的 1980 年代老街。十段旧时光、十个独立小游戏，从七岁走到七十七岁；家人会出现、变老，最后街尾只剩一道光。

**在线玩**：<https://sanbuphy.github.io/ten-memories-game/>

## 操作

- 电脑：WASD / 方向键走路，E 或空格和街坊、老人说话，`一起玩` 进入小游戏。
- 手机：左下摇杆走路，右下 `一起玩`。
- 右上角：声音开关；`+1 / +5` 是测试快进。
- 走到街尾：选“想重新活这一辈子”或“已经足够”。

单文件版已内联 Three.js、字体、全部原创音频；整个页面 6.9 MB，可离线打开。
